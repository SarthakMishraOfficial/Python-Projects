# Business Expense Tracker

## Project Overview

A command-line Python application designed to record, categorize, analyze, and monitor personal expenses against a monthly budget.

## Business Problem

Tracking expenses manually makes it difficult to understand spending patterns, calculate total spending, and monitor whether expenses remain within a defined budget.

## Objective

Build a basic expense tracking system using core Python programming concepts without external libraries.

## Features

- Add Expense
- View All Expenses
- Calculate Total Expense
- Daily Expense Analysis
- Monthly Expense Analysis
- Highest Expense
- Lowest Expense
- Monthly Budget
- Budget Status
- Remaining Budget
